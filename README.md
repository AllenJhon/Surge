# Surge 图标合集

一个合集，8 个上游图标库合并而成，3,493 个图标（去重后）。

## 在 Surge 里订阅

策略组 → 图标 → 添加外部图标库，填入：

https://raw.githubusercontent.com/AllenJhon/Surge-Icons/main/Surge-Icons.json

## 上游来源

- 整合图标合集（weigeshen，含 ①–⑭ 分类）
- fmz200の图标合集
- 图标合集 QureColor
- 黑白图标集 Quremini
- 透明图标集 QureLight-All
- 离歌图标集（注：原作者说链接已更换，此为旧链接）
- 可莉的旗帜图标
- EMBY图标集

合并规则：按上面顺序，重名图标留第一个。
