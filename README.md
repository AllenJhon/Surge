# Surge

Surge 相关的收集：图标合集 + 自用模块。

## 图标合集

8 个上游图标库合并而成，3,494 个图标（去重后）。

**在 Surge 里订阅**：策略组 → 图标 → 添加外部图标库，填入：

```
https://raw.githubusercontent.com/AllenJhon/surge/main/Surge-Icons.json
```

**上游来源**（按合并顺序，重名图标留第一个）：

- 整合图标合集（weigeshen，含 ①–⑭ 分类）
- fmz200の图标合集
- 图标合集 QureColor
- 黑白图标集 Quremini
- 透明图标集 QureLight-All
- 离歌图标集（注：原作者说链接已更换，此为旧链接）
- 可莉的旗帜图标
- EMBY图标集

每天自动拉取上游重新合并，有变化就更新。
